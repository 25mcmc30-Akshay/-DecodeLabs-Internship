# Expense Tracker

A simple command-line Expense Tracker application developed in Python. It allows users to record daily expenses, view all expenses, and calculate useful statistics such as total, average, highest, and lowest expenses.

---

## Features

- Add new expenses
- View all recorded expenses
- Calculate total expenses
- Calculate average expense
- Find the highest expense
- Find the lowest expense
- Simple command-line interface

---

## Technologies Used

- Python 3
- Lists
- Built-in Functions
- Loops
- Conditional Statements
