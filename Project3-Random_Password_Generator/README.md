# Random Password Generator

A simple command-line Random Password Generator developed in Python. This application generates secure and random passwords based on the user-specified password length using Python's built-in `random` and `string` modules.

---

## Features

- Generate random passwords instantly
- User-defined password length
- Uses uppercase and lowercase letters
- Includes numbers for stronger passwords
- Simple and user-friendly command-line interface

---

## Technologies Used

- Python 3
- random Module
- string Module
