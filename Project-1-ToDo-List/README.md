# To-Do List Application

A simple command-line To-Do List application developed in Python. The application allows users to add, view, search, and delete tasks while storing data permanently using a text file.

## Features

- Add Tasks
- View Tasks
- Delete Tasks
- Search Tasks
- Persistent Storage using File Handling

## Technologies Used

- Python
- File Handling
- OS Module

## Project Structure

```
Project-1-ToDo-List/
│── project1.py
│── tasks.txt
│── README.md
```

## How to Run

```bash
python project1.py
```
